# Sun Spot public beta

Open `index.html` in a modern browser, or serve the repository as a static website. The app remains a self-contained Leaflet page.

Run focused tests with:

```text
node tests/sunspot-core.test.js
node tests/public-beta-regression.test.js
```

The public-beta changes are developed on the `public-beta-fixes` branch and are not merged automatically.
